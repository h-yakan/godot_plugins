# Any Game Falsolu Pong (Pro)

> **Any Game Falsolu Pong Pro** — GaPongCourt composer and drop-in scenes. Priority support for Pro owners.

Game-agnostic Godot plugin packaged for AssetLib.

## Install

1. Copy `addons/any_game_falsolu_pong/` and `addons/any_game_event_bus/` into your project’s `res://addons/` directory. Skip Event Bus if you already have it from another Pro package.
2. Enable both plugins in **Project → Project Settings → Plugins**.

## What you get (Pro)

GaPongCourt composer and drop-in scenes

## Dependencies

- None

## Event Bus (included free)

This Pro zip includes **Any Game Event Bus** (`addons/any_game_event_bus/`). This plugin does not hook the bus yet; Event Bus still connects your other Midnight Anxiety addons (player, quests, inventory, notes, doors, and more).

Standalone: [Any Game Event Bus](https://hyakan.itch.io/any-game-event-bus) (placeholder)
