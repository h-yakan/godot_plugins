# Examples

This Pro zip is two addons in one purchase.

- **Skills demo:** enable Any Game Skill System, open `addons/any_game_skill_system/pro_features/scenes/ga_skill_demo.tscn`
- **Perks:** enable Modular Perks, then use the selection UI under `addons/modular_perks/pro_features/ui/` and the sample pack under `pro_features/content/sample/`
