# ga_passive_momentum

**Archetype:** Passive

Register sırasında `_apply_passive()` çalışır; bar'dan cast edilemez.

## Davranış

`context.data["move_speed_bonus"]` değerine `+0.1` ekler. Oyun tarafı bu bonusu hareket hızına uygular.

Bar'da pasif slot olarak gösterilir (gri modulate, tıklanamaz).
