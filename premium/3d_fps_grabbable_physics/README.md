# 3D FPS Grabbable Physics

Fully free / open-source Godot plugin (MIT). No separate Pro edition.

## Install

1. Copy the `addons/3d_fps_grabbable_physics/` folder into your project's `res://addons/` directory.
2. Enable the plugin in **Project → Project Settings → Plugins**.

## What you get

Complete grab/throw RigidBody3D helper.

## Dependencies

- None

- `core/` — full plugin runtime
