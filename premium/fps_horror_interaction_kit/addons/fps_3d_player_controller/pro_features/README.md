# Pro features — fps_3d_player_controller

This folder holds Pro-only modules (UI, prefabs, samples, convenience).

Lite installs omit this directory. Core never hard-depends on these scripts.

`ga_fps_player.tscn` uses `res://addons/fps_3d_interaction_ray/core/scripts/ga_interaction_ray.gd`. That addon is bundled next to this plugin in the Pro zip.
