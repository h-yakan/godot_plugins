# Any Game Skill System (Lite)

> This is the core (Lite) version of **Any Game Skill System**. Skill bar, slots, tooltips, samples, and perk drafts ship together in **Perks & Skills Kit** (Pro): [https://hyakan.itch.io](https://hyakan.itch.io)

Game-agnostic Godot plugin packaged for AssetLib.

## Install

1. Copy the `addons/any_game_skill_system/` folder into your project’s `res://addons/` directory.
2. Enable the plugin in **Project → Project Settings → Plugins**.

## What you get (Lite)

Skill kinds, definitions, controller, host, loader API.

## Dependencies

- None

## Structure

- `core/` — shared runtime (identical between Lite and Pro where applicable)
- No `pro_features/` in Lite
