# Any Game Falsolu Pong (Lite)

> This is the core (Lite) version of **Any Game Falsolu Pong**. If you need advanced features (GaPongCourt composer and drop-in scenes), check out the Pro Version on Itch.io: [https://hyakan.itch.io](https://hyakan.itch.io)

Game-agnostic Godot plugin packaged for AssetLib.

## Install

1. Copy the `addons/any_game_falsolu_pong/` folder into your project’s `res://addons/` directory.
2. Enable the plugin in **Project → Project Settings → Plugins**.

## What you get (Lite)

GaPongBall + GaPongPaddle physics API.

## Dependencies

- None

## Structure

- `core/` — shared runtime (identical between Lite and Pro where applicable)
- No `pro_features/` in Lite
