# Clyde Dialogue Host (Lite)

> This is the core (Lite) version of **Clyde Dialogue Host**. If you need advanced features (Dice roller, event/stat/modifier stores, persistence, examples, ready scene), check out the Pro Version on Itch.io: [https://hyakan.itch.io](https://hyakan.itch.io)

Game-agnostic Godot plugin packaged for AssetLib.

## Install

1. Copy the `addons/clyde_dialogue_host/` folder into your project’s `res://addons/` directory.
2. Enable the plugin in **Project → Project Settings → Plugins**.

## What you get (Lite)

Dialogue host, triggers, presenters (dice/persistence disabled until Pro).

## Dependencies

- `clyde (opensource package)`

## Structure

- `core/` — shared runtime (identical between Lite and Pro where applicable)
- No `pro_features/` in Lite
