# FPS 3D Interaction Ray

Fully free / open-source Godot plugin (MIT). No separate Pro edition.

## Install

1. Copy the `addons/fps_3d_interaction_ray/` folder into your project's `res://addons/` directory.
2. Enable the plugin in **Project → Project Settings → Plugins**.

## What you get

Complete interaction ray (interact/place/grab).

## Dependencies

- None

- `core/` — full plugin runtime
