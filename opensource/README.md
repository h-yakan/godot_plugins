# Opensource packages

AssetLib-ready packages. Copy each package's `addons/<name>/` into a Godot project.

## Fully free (no Pro edition)

These ship complete in opensource only:

- `fps_3d_camera_shake`
- `fps_3d_interaction_ray`
- `3d_fps_grabbable_physics`
- `3d_fps_physics_doors`
- `3d_item_placement_slots`
- `3d_interactable_tv_viewport`
- `fps_horror_eye_blink`
- `fps_horror_ear_cover`
- `clyde` (upstream Clyde Dialogue)

**Any Game Event Bus is Pro-only.** Lite plugins still work alone; Event Bus is the paid hub that connects them. Placeholder: [https://hyakan.itch.io/any-game-event-bus](https://hyakan.itch.io/any-game-event-bus). Every Pro zip includes Event Bus for free.
