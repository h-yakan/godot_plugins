# Any Game Settings Persistence (Lite)

> This is the core (Lite) version of **Any Game Settings Persistence**. If you need advanced features (Input remapping encode/decode helpers), check out the Pro Version on Itch.io: [https://hyakan.itch.io](https://hyakan.itch.io)

Game-agnostic Godot plugin packaged for AssetLib.

## Install

1. Copy the `addons/any_game_settings_persistence/` folder into your project’s `res://addons/` directory.
2. Enable the plugin in **Project → Project Settings → Plugins**.

## What you get (Lite)

Video/audio/headbob ConfigFile persistence.

## Dependencies

- None

## Structure

- `core/` — shared runtime (identical between Lite and Pro where applicable)
- No `pro_features/` in Lite
