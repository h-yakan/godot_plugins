1. Felsefe ve Özellik Ayrımı (Feature Split)En kritik aşama burasıdır. Topluluk, "Lite" sürümün bilerek sakat bırakıldığını hissederse funnel çöker. Ayrımı işlevsellik üzerinden değil, zaman tasarrufu ve ölçeklenebilirlik üzerinden yapmalısın.Özellik TipiLite Sürüm (AssetLib / GitHub)Pro Sürüm (Itch.io)Temel Mantık (Core)Tamamen çalışır, limitsizdir. (Örn: Sınırsız envanter slotu)Lite ile aynı çekirdek kodu kullanır.Veri YönetimiBasit JSON veya Dictionary tabanlı kayıt.Şifrelenmiş (Encrypted) Save, SQLite entegrasyonu.Editör Araçları (UX)Sadece kod (API) veya Inspector üzerinden manuel veri girişi.Özel Godot Editor pencereleri, görsel veri (Node) bağlama arayüzleri.Örnek SahnelerSadece mekaniğin çalıştığı tek bir gri kutu (greybox) sahne.Tamamen tasarlanmış, farklı senaryoları (Örn: Menü, Oyun İçi, Sandık) gösteren 3-4 demo sahne.Dış BağlantılarSadece yerel (local) çalışır.Steamworks (Başarımlar/Leaderboard), Rest API / Backend entegrasyonları hazır gelir.

2. Teknik Klasör ve Güncelleme MimarisiBir kullanıcı Lite sürümü projesine kurup üzerine kod yazdıktan sonra Pro sürümü satın aldığında, hiçbir kodu bozulmadan sadece klasörü değiştirerek yoluna devam edebilmelidir. Bunu sağlamazsan iadeler ve kötü yorumlar başlar.Örnek Klasör Yapısı:Projeyi tasarlarken addons/ klasörünün içini modüler kurmalısın.Plaintextres://
└── addons/
    └── Seninsistemin/
        ├── plugin.cfg          (Versiyon: 1.0.0-Lite veya 1.0.0-Pro)
        ├── core/               (Lite ve Pro'da tamamen AYNI olan çekirdek scriptler)
        │   ├── system_manager.gd
        │   └── data_parser.gd
        ├── pro_features/       (Lite sürümde bu klasör YOKTUR veya boştur)
        │   ├── sqlite_handler.gd
        │   └── editor_dashboard.tscn
        └── examples/           (Demo sahneler)
Mimarinin Altın Kuralı: Lite sürümdeki scriptler hiçbir zaman pro_features klasöründeki bir scripti doğrudan referans almamalıdır (Dependency Error almamak için). Pro özelliklerini sisteme has_method() veya ClassDB.class_exists() kontrolleriyle veya modüler olarak bağlamalısın.

Lite Sürüm Hazırlığı (Trafik Kaynağı)Lite sürümün tek bir amacı vardır: Geliştiricinin sorununu 5 dakikada çözmek ve ona "Bu kodu yazan kişi ne yaptığını çok iyi biliyor" dedirtmek.Temiz Dökümantasyon: GitHub README dosyan kusursuz olmalı. Geliştirici, scripti Hangi Node'a takacağını, hangi fonksiyonu çağıracağını anında görmeli.Açık Kaynak Lisansı: MIT lisansı ile paylaş. Godot topluluğu MIT lisansına bayılır.Hatasızlık: Lite sürüm çok özellikli olmasın ama asla hata (bug) vermesin. Güven, bu aşamada inşa edilir.

4. Funnel Köprüsü (Zarif Satış)Kullanıcıyı Lite sürümden Pro sürüme geçirirken spam yapmadan görünür olmalısın.GitHub/AssetLib Vitrini: Açıklamanın en üstüne ve en altına şu metni koy:*> "This is the core version of [Sistem Adı]. If you need advanced features like Encrypted Saves, SQLite support, and custom Editor Dashboards, check out the Pro Version on Itch.io [Link]."Godot Editör İçi Yönlendirme (Opsiyonel ama Etkili): Godot'un print_rich() fonksiyonunu kullanarak, plugin ilk aktif edildiğinde (sadece 1 kereye mahsus) Godot konsoluna zarif bir mesaj basabilirsin:GDScriptprint_rich("[color=green][Sistem Adı] Lite v1.0 initialized.[/color] Need database support? Check out the Pro version: [url=https://seninlinkin.itch.io]Link[/url]")
Kod İçi Yorumlar: Geliştiriciler kodu okur. Lite sürümde karmaşık bir işlemi manuel yapmaları gereken yere yorum satırı bırak:# Note: In the Pro version, this data serialization is handled automatically via the custom Editor Dashboard.

5. Pro Sürüm Paketi (Kapanış)İnsanlar Itch.io'ya geldiklerinde koda değil, satın alacakları zamana para verirler.Fiyatlandırma: Başlangıç için $9.99 - $14.99 arası en tatlı noktadır (Sweet spot). Godot kitlesi henüz Unreal kitlesi gibi $50-$100 vermeye tam alışkın değil.Öncelikli Destek Vaadi: "Pro sürüm sahiplerine Discord üzerinden veya e-posta ile öncelikli teknik destek (priority support) verilir" ibaresi satışları %30'a kadar artırır. Geliştiriciler, tıkandıklarında kodu yazan kişiye ulaşabilmenin güvenini satın alırlar.Hazır Şablonlar: Sadece sistemi satma, o sistemin kullanıldığı 3 farklı oyun türü şablonunu (Örn: FPS için, RPG için, Strateji için hazır ayarlanmış sahneler) Pro pakete dahil et.
