# Any Game Falsolu Pong

Spin/Magnus eğrili 2D pong kit'i. “Falsolu” = top spin eğrisi; fake-3D değil.

## Klasörler

| Klasör | İçerik |
|--------|--------|
| [scripts/](scripts/README.md) | Ball, paddle, court script'leri |
| [scenes/](scenes/README.md) | Hazır sahneler |

## Kurulum

1. `res://godot_plugins/any_game_falsolu_pong/` veya `res://addons/any_game_falsolu_pong/`
2. **Project → Project Settings → Plugins** → **Any Game Falsolu Pong**
3. Autoload gerekmez

## Hızlı başlangıç

```
res://godot_plugins/any_game_falsolu_pong/scenes/ga_pong_court.tscn
```

Detay: [scenes/README.md](scenes/README.md)

Skill sistemi ile bağımsız; birlikte kullanılabilir ([any_game_skill_system](../any_game_skill_system/README.md)).

Ricochet orijinal dosyaları değiştirilmedi.
